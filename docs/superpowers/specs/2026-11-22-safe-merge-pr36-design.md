# Safe merge of PR #36 (Batch 3 stories) — design

Date: 2026-11-22

## Intent

Unblock PR #36 (`content: Batch 3 — five new Muslim story pairs`) by updating its
branch from `main`, resolving the generated-doc conflicts, verifying, and merging —
without losing either the batch-3 content or the newer batch-4 / EGM docs work
already on `main`.

## Goals

- Preserve all five batch-3 EN/AR story pairs, four portraits, and `todo-batch-3.md`.
- Preserve all content already merged in #37 and #38, including the regenerated
  indexes that currently report 101 Muslims.
- End with a clean, mergeable PR #36 and a green CI run.

## Non-goals / anti-goals

- No story content edits, no rewriting of frontmatter, no changes to #38's stories.
- No hand-editing of generated index files (`docs/existing-muslims.md`,
  `docs/muslim-names.md`).
- No closing/deleting PR #36 or its branch.

## Constraints

- `docs/existing-muslims.md` and `docs/muslim-names.md` are generated by
  `node scripts/regenerate-doc-indexes.mjs` and must never be hand-edited.
- Repo policy: branches are preserved after merge; GitHub Flow requires
  verification before merge.
- Working tree is clean on `main`; `content-batch3-stories` is the PR branch.

## Approaches considered

1. **Merge `main` into the branch** (chosen). Keeps PR #36's commit and review
   context, matches the repo's existing merge-commit history, and touches only the
   two generated docs during conflict resolution.
2. Rebase the branch onto `main`. Linear history, but rewrites the PR commit and
   offers no benefit here since the repo already merges PRs.
3. Close #36 and recreate it from a fresh branch. Discards PR context and risks
   losing the batch-3 work; rejected.

## Design

- Check out `content-batch3-stories`, merge `origin/main` into it.
- The only expected conflicts are `docs/existing-muslims.md` and
  `docs/muslim-names.md`. Resolve by taking `main`'s versions, then run
  `node scripts/regenerate-doc-indexes.mjs` so both files are rebuilt from all
  story frontmatter (expected: 106 Muslims, including all 5 batch-3 and 2 batch-4
  names). A dry run of this resolution already produced 106 with all seven names.
- Verify with `pnpm lint`, `pnpm test` (vitest), and `pnpm build`.
- Push the updated branch; confirm GitHub reports #36 as mergeable with green CI;
  merge #36 with a merge commit.
- Return to `main`, pull, and leave the `content-batch3-stories` branch in place.

## Left to the implementer

- Exact conflict-resolution commands and verification output belong in the
  execution plan; no further design decisions are open.
